## Core features

### 1. Duplicate and similar photo detection
AIWise Cleaner identifies:
- exact duplicates
- near-identical images
- same-scene variations with different crops or small edits
- visually similar photos that are hard to spot manually

It uses a fast comparison pipeline that avoids expensive full-library pairwise checks and focuses on the most relevant groups first.

### 2. Fast on-device scanning
The app is optimized for speed and efficiency:
- parallel thumbnail processing
- one decode per image
- SHA256-based exact match checks for identical previews
- dHash + aHash perceptual comparisons for visual similarity
- time-windowed grouping to reduce unnecessary comparisons

This allows large libraries to be scanned far more quickly than traditional brute-force duplicate detection.

### 3. Optional AI refinement
For the remaining borderline matches, the app can optionally use an on-device ML model such as MobileNet feature embeddings for extra refinement. This helps improve the accuracy of similar-image grouping while keeping the process fast and privacy-focused.

### 4. Smart review before deleting
Every match is grouped visually so users can review the images together and decide exactly what to keep or remove. This gives users confidence and keeps deletion intentional rather than automatic.

### 5. Privacy-first design
AIWise Cleaner is designed to work with your photos locally on-device whenever possible. The app minimizes server dependency and keeps image processing focused on the user’s own library.

### 6. Built for modern mobile photo libraries
The app supports large photo collections and is built to handle the realistic behavior of modern camera rolls, where duplicates often appear in bursts over time.

## How it works

### Step 1: Scan your library
The app loads your photo metadata and generates a lightweight preview thumbnail for each image.

### Step 2: Compare intelligently
It uses:
- exact preview hash matching for duplicates
- perceptual hashing for near-duplicate detection
- optional AI embeddings for ambiguous matches

### Step 3: Group results
Photos are organized into similarity groups, making it easy to compare originals side by side.

### Step 4: Review and delete
Users can select which images to keep and which to remove before confirming deletion.

## FAQ

### Is AIWise Cleaner only for duplicates?
No. It can detect exact duplicates, similar images, and near-identical versions of the same moment.

### Does it run entirely on-device?
Core similarity analysis is designed to work efficiently on-device, with optional AI refinement available for more advanced matching.

### Can I decide what gets deleted?
Yes. The app groups photos together and lets you manually review each set before deleting anything.

### Is the app safe to use with large libraries?
Yes. The scanning pipeline is optimized to work with large photo collections using thumbnail-based comparisons and time-windowed matching rather than full pairwise comparison.

### Does it support iPhone and Android?
Yes. The app is built for both iOS and Android.
